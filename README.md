# 💫 About Me:
I'm a Senior Analyst at Accenture, building server-side applications with Node.js (Express.js, Hapi.js) and Java with Spring Boot, paired with React.js, Vue.js, and Nuxt.js on the frontend. I work across MySQL, PostgreSQL, CosmosDB, and MongoDB depending on what the problem needs.

Most of what I ship sits at the intersection of clean API design and frontend performance — I care less about chasing every new framework and more about whether the thing I built is still boring and reliable six months later.
